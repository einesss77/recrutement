# B&M Digital Consulting — prototype Consulting V2

Code du site Consulting livré par le développeur, ajouté séparément de l'application de recrutement existante. Aucun fichier de cette application n'est modifié.

## Lancer

Ouvrir `index.html` dans un navigateur. HTML, CSS et JavaScript sont autonomes : aucun build, paquet, serveur ou secret requis.

## Contenu

Deux axes : mise à disposition de profils individuels ou squads ; solutions sur mesure.
Navigation : Accueil, Profils & squads, Solutions sur mesure, Notre approche, Contact.

## Vérification du 17 octobre 2026 (Europe/Paris)

66 contrôles Playwright/Chromium réussis sur le fichier source à 1440×1000, 390×844 et 768×1024 : navigation, menu mobile, CTA, validation du formulaire, absence de débordement et d'erreur JavaScript. Le fichier publié est une copie binaire identique à ce fichier testé. Recherche par motifs de clés privées et de jetons usuels : aucune correspondance dans le HTML ; ce contrôle limité ne constitue pas un audit de sécurité.

## Limites

Prototype français, pas site de production. Formulaire de démonstration sans envoi ni stockage : utiliser uniquement des données fictives. Aucun backend de contact ni version anglaise. Les textes commerciaux, coordonnées, identité finale et mentions légales restent à valider avant mise en production.

L'ajout dans GitHub ne constitue pas un déploiement. La configuration de l'application de recrutement et son déploiement ne sont pas modifiés.
